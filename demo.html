🚀 QRコード生成ページを開く 🔍 検証ツールを開く

📋 システム概要

このシステムは、QRコードを使った出退勤記録システムです。 オフライン環境のタブレットやスマートフォンでQRコードを生成し、 従業員のスマートフォンで読み取ることで出退勤を記録できます。

📴

オフライン対応

PWA技術により、インターネット接続なしでも動作します

🔒

セキュア

JWT トークンで署名され、3分間の有効期限付き

📱

モバイル最適化

Android・iPhoneのブラウザで快適に動作

⚡

高速

ボタンをタップするだけで即座にQRコード生成

🚀 クイックスタート

1. QRコード生成ページの設定

  1. QRコード生成ページを開く
  2. ページ下部の「設定」エリアまでスクロール
  3. 以下の情報を入力:
    • デバイスID: 一意の識別子（例: TABLET001）
    • パスコード: サーバーに登録するパスコード
    • サーバーURL: 記録サーバーのURL
  4. 「設定を保存」ボタンをクリック
💡 ヒント: 設定はLocalStorageに保存されるため、次回アクセス時も維持されます。

2. サーバーの設定（管理者向け）

# 依存関係のインストール
cd server
npm install

# デバイスの登録
node register-device.js TABLET001 mypassword123

# サーバーの起動
npm start

3. 出退勤の記録

  1. タブレット等で「出勤」または「退勤」ボタンをタップ
  2. QRコードが表示される（出勤=青、退勤=赤）
  3. 従業員がスマートフォンでQRコードをスキャン
  4. 初回アクセス時は名前を登録
  5. 画面に受付完了メッセージが表示される
✅ 完了: サーバーのログファイルに自動的に記録されます。

🎯 主な機能

QRコード生成

  • ボタンタップで即座にQRコード生成
  • 出勤と退勤で色が変わる（青/赤）
  • トークンの有効期限は3分間
  • 1分後または手動タップで自動消去
  • 残り時間のカウントダウン表示

セキュリティ

  • JWT（HS256）による署名
  • デバイスID、タイムスタンプ、動作タイプを含むペイロード
  • パスコードはマスク表示（***）で保護
  • サーバー側でトークンを検証

ログ管理

  • 有効なリクエストと無効なリクエストを分離
  • 年月ごとにファイルを分割
  • デバイスID、名前、出退勤、タイムスタンプを記録

PWA機能

  • オフラインでも完全動作
  • Stale-While-Revalidate キャッシュ戦略
  • ホーム画面に追加可能
  • アプリのような使用感

🔧 検証ツール

検証ツールは、 生成されたトークンの妥当性を確認するためのツールです。

使い方

  1. 検証ツールページを開く
  2. パスコードを入力して保存
  3. QRコードをスキャンしてURLにアクセス（?token=...）
  4. トークンの妥当性と内容が表示される
💡 用途: 開発時のデバッグや、トークンの内容確認に便利です。

⚠️ トラブルシューティング

QRコードが生成されない

  • 設定がすべて入力されているか確認
  • ブラウザのコンソールでエラーを確認
  • パスコードがサーバーに登録されているか確認

トークンが無効と表示される

  • デバイスIDとパスコードが一致しているか確認
  • トークンの有効期限（3分）が切れていないか確認
  • サーバー側にデバイスが登録されているか確認

オフラインで動作しない

  • Service Workerが正しく登録されているか確認
  • 最初のアクセス時はオンラインでキャッシュする必要がある
  • ブラウザのデベロッパーツールでService Workerの状態を確認
⚠️ 注意: 最初の訪問時はインターネット接続が必要です。 その後、すべてのリソースがキャッシュされ、オフラインで動作します。
